# 🔌 Rekomendasi Ekstensi VS Code

Untuk kenyamanan pengembangan project ini, sangat dianjurkan menggunakan ekstensi berikut:

## 🐘 PHP & Laravel
1. **PHP Intelephense**: Autocomplete, Go-to-definition, dan integrasi PHP yang sangat cepat.
2. **Laravel Extension Pack**: Paket lengkap berisi Snippets, Artisan Run, dan Blade Spacer.
3. **Laravel Extra Intellisense**: Membantu memberikan saran nama file view, route, dan konfigurasi config di dalam PHP.

## ⚛️ JavaScript & Next.js
1. **ES7+ React/Redux/React-Native snippets**: Snippet cepat untuk membuat komponen React (ketik `rfce` atau `rafce`).
2. **TypeScript Hero**: Mempermudah manajemen import library di Next.js.
3. **Tailwind CSS IntelliSense**: Autocomplete dan preview warna CSS langsung di editor.

## 🐳 Docker & Dev Tools
1. **Docker**: Mengelola container, images, dan volume langsung dari sidebar VS Code.
2. **Postman / Thunder Client**: Untuk mengetes API Backend sebelum diintegrasikan ke Frontend.
3. **Auto Close Tag & Auto Rename Tag**: Mempermudah manipulasi tag HTML/JSX.

---

## 🎨 Tips Editor
- Gunakan font **JetBrains Mono** atau **Inter** untuk keterbacaan kode yang lebih baik.
- Color Theme yang direkomendasikan: **One Dark Pro** atau **Tokyo Night**.
